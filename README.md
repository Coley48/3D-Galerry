# 云栖影像馆 · Three.js 原型

这是一个可运行的原创三维展厅原型。它用于验证新展厅的空间语言、作品交互与性能治理方式，不包含或复用任何第三方线上展厅的模型、贴图、代码或数据。

## 技术框架

```text
展示界面（Vue 3 + TypeScript）
  ├─ 首页 / 导览 / 作品详情 / 地图 / 筛选 / 无障碍图文
  └─ 内容状态、路由与响应式布局

三维运行时（Three.js）
  ├─ SceneManager：展区挂载、LOD、可见性与资源释放
  ├─ CameraController：入口、自由探索、作品聚焦、自动导览
  ├─ InteractionLayer：射线拾取、热点、展签、作品详情
  └─ PerformanceProfile：高画质 / 性能模式、阴影与像素比控制

资源层（CDN / glTF 2.0）
  ├─ 几何：Meshopt 或 Draco 压缩
  ├─ 纹理：KTX2 / BasisU；缩略图、展墙图、详情图三级
  ├─ 分包：入口 / 展区 / 单件作品，按需加载和释放
  └─ 共享：展框、灯具、植物等用实例化与共享材质

内容层（CMS / API）
  └─ 展览 → 展区 → 展墙 → 作品 → 图文 / 音视频 / 作者信息
```

当前原型先以 **Vite + TypeScript + Three.js r186** 直接验证空间与交互，避免 UI 框架干扰三维调试。正式版本将把 `src/main.ts` 拆为 Vue 页面、场景服务和内容适配器，但不会改变场景与资源层的接口。

### 核心设计约束

- 不直接依赖任何未获授权的线上模型、贴图、代码或展览数据；
- 房间以“内净尺寸 + 墙厚”统一计算：前后墙跨满外宽，左右墙只延伸至前后墙内侧；顶面与墙顶、地面与墙底均为接触而非相交，避免侧视时的 Z-fighting；
- 首屏只加载入口厅、低清预览和必要交互；访客靠近展区才加载高清作品与该区模型；
- 离开展区时对纹理、材质和几何调用 `dispose()`，以释放 GPU 显存；
- 流式卸载以房间与门户可见性为准，不能仅用短距离阈值；即使相机位于透明外墙之外，只要仍能看入房间，作品就必须继续保留；
- 每件摄影作品准备 `thumbnail`、`wall`、`detail` 三个资源级别，详情图只在打开作品后加载；
- 重复展板、灯光、展框共享几何/材质，图片优先使用图集或纹理数组，避免“一张图一套材质”。

### 资源与性能预算

| 指标 | 目标 |
| --- | --- |
| 首屏三维资源 | 10–20 MB |
| 可见纹理显存 | 256–400 MB |
| 常规视角绘制调用 | 尽量低于 200 |
| 移动端像素比 | 最多 1；关闭高成本阴影与后期 |
| 展品大图 | 用户打开详情时才按需请求 |

## 当前原型已完成

- Vue 之外可独立运行的 Vite + TypeScript + Three.js r186 三维场景；
- 程序化原创空间：展厅结构、灯光、展框、台座与雕塑；
- 一张原创 AI 生成测试摄影作品；
- 单击作品查看详情、双击作品直接聚焦、自动导览、性能模式、响应式界面；
- 画作正面显示作品图，背面统一为白色画板；不再添加画作下方文字。主展与侧展挂墙，室内斜置作品使用木质三棱锥 A 型画架（双前腿、后撑腿、承托横档）支撑；
- 自动入场、回到入口与作品聚焦均可被用户拖拽或缩放即时打断，避免自动相机逻辑覆盖自由探索；
- 相机在房间外环视时，自动淡化所有位于相机外侧的墙面、顶面或地面；在立方体顶点外会同时淡化两到三个相邻面，避免结构遮挡视线；
- `artworks` 结构化内容配置，为后续接 CMS、图文/音视频作品和已授权 glTF 资产预留接口；
- 按分区管理的 `zones`，可扩展为真实的资源懒加载与卸载流程。

## 项目结构

```text
src/
  assets/               原创测试作品图
  main.ts               三维场景、资源、相机、交互与性能模式
  style.css             响应式展厅界面
  vite-env.d.ts         静态资源类型声明
index.html              展厅 UI 容器
```

## 启动

本机已通过 `nvm use 22.23.2 && npm run build` 校验。项目根目录的 `.nvmrc` 会固定该版本。

```bash
nvm use
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 后续接入已授权资产

1. 将展厅模型导出为 glTF 2.0；优先使用 Draco 或 Meshopt 几何压缩、KTX2/BasisU 纹理；
2. 按“入口 / 展区 / 作品详情”拆分为独立资源包；
3. 只在访客靠近时加载高清作品纹理，离开展区时调用 `dispose()` 释放材质、纹理和几何；
4. 让多个展板共享几何与材质，图片采用纹理数组或图集，避免为每张图新建一整套材质。

接入资产前应确认拥有模型、纹理、展品图与相关数据的使用授权。
